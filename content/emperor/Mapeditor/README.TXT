Welcome Commander,

	Due to popular demand, we have released this version of the map editor so the
fans can begin building incredible maps!  This is the very same editor that we used to
create all the official maps in the game, and the additional map packs.  It contains
all the features & tools neccesssary to create maps, however, it is unlike other editors
you may familiar with.  The learning curve on the editor is very high, so we have
provided a tutorial to get you through the basics.  We HIGHLY RECOMMEND using the
Tutorial, even if you are an experienced RTS map-maker.

Have fun, and remember to post your maps for other to enjoy!!

Regards,

The EMPEROR team.

SHARING MAPS WITH OTHERS
-------------------------
+  Emperor does not support automatic download of player made maps.  Instead, you will need
to download the map files yourself, and install into the \DATA\MAPS directory.
